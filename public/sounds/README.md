# Sound Files for Scan BIB Feature

Place the following sound files in this directory:

1. `success-beep.mp3` - Short beep sound for successful scan (1-2 seconds)
2. `error-beep.mp3` - Error sound for failed scan (1-2 seconds)

## Recommended Sources

You can download free sound effects from:
- https://www.zapsplat.com
- https://freesound.org
- https://mixkit.co/free-sound-effects/

## File Requirements

- Format: MP3
- Duration: 1-2 seconds max
- Size: Keep under 50KB for fast loading
